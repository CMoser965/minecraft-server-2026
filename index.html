Setup Guide

Unlucky Golem's 2026 - Setup

📋 Prerequisites
  • Minecraft Java Edition (Official Launcher)
  • Java 17 (or Java 21). Download Here.
Step 1: Install Forge

We are running on Minecraft 1.20.1.

  1. Download the Forge Installer (1.20.1).
  2. Run the downloaded .jar file.
  3. Select "Install client" and click OK.
Step 2: Download & Sync

We use a custom sync script to manage mods automatically.

  1. Download the Pack: Click the "Code" -> "Download ZIP" button on the GitHub repository.
  2. Extract: Unzip the folder to your Documents or Games folder.
  3. Run: Double-click update-mods-client.bat.

This script will download all mods directly to your Minecraft folder.

Step 3: Configure RAM (CRITICAL)
⚠️ IMPORTANT: You must allocate more RAM or the game will crash.
  1. Open the Minecraft Launcher -> Installations tab.
  2. Find the new forge-1.20.1 profile -> Click ... -> Edit.
  3. Click More Options.
  4. Find JVM Arguments. Change -Xmx2G to -Xmx8G.
  5. Click Save.
Step 4: Play
  • Select your profile and hit Play.
  • Go to Multiplayer -> Add Server.
  • Address: YOUR_PUBLIC_IP_HERE

🔄 How to Update

When new mods are added, just go to your extracted folder and run update-mods-client.bat again. It handles everything.

🛠️ Troubleshooting

  • Lag? Turn VSync OFF and set Max Framerate to Unlimited.
  • Mouse Stutter? Lower your mouse polling rate to 500Hz.
  • Crash? Verify you set the RAM to -Xmx8G.
