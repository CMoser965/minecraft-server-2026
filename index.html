Setup guide

Unlucky Golem's 2026 — Setup

1

Prerequisites

  • Minecraft Java Edition
  • Java 17 or 21 — download here
2

Install Forge

Running on Minecraft 1.20.1.

  1. Download the Forge Installer (1.20.1)
  2. Run the .jar file
  3. Select Install client and click OK
3

Download & sync mods

  1. Download this repo as a ZIP (GitHub → Code → Download ZIP)
  2. Extract somewhere permanent (Documents, Games, etc.)
  3. Double-click update-mods-client.bat
The script downloads all mods directly to your Minecraft folder. Run it again whenever mods update.
4

Allocate RAM

Open the Minecraft Launcher → Installations → find forge-1.20.1 → Edit → More Options → change -Xmx2G to -Xmx8G → Save.

5

Play

Select the forge-1.20.1 profile and hit Play. Multiplayer → Add Server → enter the address you were given.

Troubleshooting

  • Crashes on startup — did you set RAM to -Xmx8G?
  • Lag spikes — turn VSync off, set framerate to Unlimited. Lower mouse polling rate to 500Hz.
  • Can't connect — server might be restarting. Try again in a minute.
