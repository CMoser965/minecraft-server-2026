Cozy Days

Exploration-focused with stunning terrain, new creatures, good food, and light adventure. One-click install via Modrinth App.

Installation
1

Install the Modrinth App

A free launcher that manages everything for you — no manual mod downloading.

Download Modrinth App

Run the installer after it downloads.

2

Sign in with Microsoft

When the app opens, click Sign in and log in with the Microsoft account your copy of Minecraft is tied to. After signing in, your username should appear at the top of the app.

Not sure which account? Check your email for a receipt from Microsoft when the game was purchased.
3

Import the modpack

Download the pack file, then import it into the Modrinth App.

Download cozy-days.mrpack

In the Modrinth App: Library → + → Import → select the file you just downloaded. The app will handle the rest.

First launch downloads all mods — takes 2–3 minutes.
4

Allocate memory

In the Modrinth App, click ··· next to Cozy Days → Edit → Java tab → set Maximum memory to 6144 MB → Save.

5

Play

Hit Play. First launch takes about a minute. To join the server: Multiplayer → Add Server → enter the address you were given.

Troubleshooting
  • Can't sign in — make sure you're using the email the Minecraft account was purchased on. Try signing in at minecraft.net to confirm it works.
  • Game crashes on startup — go back to step 4 and set memory to at least 4096 MB.
  • Low FPS — open Video Settings in-game and turn Shaders off. The game will look plainer but run much faster on slower hardware.
  • Can't connect to server — double-check the address, including any : and numbers after it. The server might also just be offline.
