Cozy Days

Fabric 26.1.2  ·  Cozy exploration, cute critters, pretty landscapes

Setup Guide

Follow these steps in order. Takes about 5 minutes.

1 Install the Modrinth App

This free app handles everything — no manual mod downloading needed.

Download Modrinth App

Click the big download button on their site, then run the installer file when it downloads.

2 Sign in with your Microsoft account

When the Modrinth App opens, you'll see a Sign in button. Click it — it will open a Microsoft login page in your browser.

Sign in with the same email and password you use for Minecraft (the one the game was purchased on). After logging in, go back to the Modrinth App — it should show your username at the top.

If you're not sure which account, check your email for a receipt from Microsoft/Minecraft when the game was purchased.
3 Download and import the modpack

First, download the pack file:

Download cozy-days.mrpack

Then, in the Modrinth App:

  1. Click Library in the left sidebar
  2. Click the + button (top right)
  3. Choose Import
  4. Select the cozy-days.mrpack file you just downloaded
The app will download all the mods automatically. This takes 2–3 minutes — just leave it running.
4 Set your RAM (important!)

The game needs more memory than the default. In the Modrinth App:

  1. Find your new Cozy Days instance
  2. Click the three dots ··· next to it
  3. Click Edit
  4. Go to the Java tab
  5. Set Maximum memory to 4096 (or higher if your PC has 16GB+ RAM, use 6144)
  6. Click Save
5 Play!

Click the big green Play button on your Cozy Days instance. The first launch takes about a minute while everything loads — that's normal.

To join the server once the game opens:

  1. Click Multiplayer
  2. Click Add Server
  3. In the Server Address box, type the address you were given
  4. Click Done, then click the server to join

Troubleshooting

  • Can't sign in / login not working? Make sure you're using the email the Minecraft account was purchased on. Try signing in at minecraft.net first to confirm it works.
  • Game crashes on startup? Go back to Step 4 and make sure memory is set to at least 4096.
  • Very laggy / low FPS? In Video Settings inside the game, turn Shaders off. The game looks more basic but runs much faster on slower PCs.
  • Can't connect to the server? Double-check the address is typed exactly right, including any : and numbers after it. The server might also be offline — ask first!
