Cozy Days

Fabric 1.20.1  ·  Cozy exploration, cute critters, pretty landscapes

Quick Install (recommended)

1 Install the Modrinth App

This is a free launcher that installs the modpack for you in one click. No fiddling with folders.

Download Modrinth App

Click the big download button on their site. Run the installer when it downloads.

2 Import the pack file

Download the .mrpack file below, then in the Modrinth App go to Browse → click the folder icon → Import from file → select the file you downloaded.

Download cozy-days.mrpack
The app will download all the mods automatically. This takes a couple of minutes on first launch.
3 Set your RAM

Once the instance is created, click the three dots next to it → Edit → Java tab. Set Maximum memory to 6144 MB (6 GB). Click Save.

4 Play!

Hit the big green Play button. First launch takes a minute to load all the mods.

To join the server: Multiplayer → Add Server → enter the address you were given.

Troubleshooting

  • Game crashes on startup? Make sure RAM is set to at least 4096 MB (4 GB) in the Modrinth App.
  • Very laggy / low FPS? In Video Settings, turn Shaders off. The game will look more plain but run much faster.
  • Can't connect to server? The server might be offline — ask first!
